# Remaster R3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tighten the R2 prototype (rhythm, type ceiling), apply the client's changes to Home, Certified, Interpretation and the quote flow, and add Blog, FAQ and Contacto, so the P4 start gate covers every menu page.

**Architecture:** Static prototype in `prototype/`: pages in `src/pages/*.html` assembled by `build.mjs` (`<!-- @include name k="v" -->` from `src/components/`), Tailwind 4 tokens in `src/styles/app.css`, page CSS/JS per round. R3 adds one stylesheet `src/styles/remaster-r3.css`, one script `src/assets/js/remaster-r3.js`, a few components and four pages. Tests are `node --test` contract tests on `src/`/`dist/` plus Playwright browser tests on the built `dist/`.

**Tech Stack:** HTML, Tailwind CSS 4.1.11, vanilla JS, Node 24 `node:test`, Playwright (pinned path from `check.mjs`), Python only for `tools/halftone.py` (scratchpad venv).

**Spec:** `audit/remaster-r3/decisions/r3-design.md` (approved 2026-11-05). Task 0 turns it into `docs/specs/brg-84.md`, the testable contract.

## Global Constraints

- Only `prototype/` code changes; no `site/` (CLAUDE.md §5; this round's gate is the design doc).
- Tokens only: no hex values or font-family literals in R3 CSS; colours, radii, type and spacing from `app.css` `@theme`.
- Contrast ≥ 4.5:1 computed for every new text pair; amber (`#e3a148`) only on Tinta.
- Vanilla JS, no new packages (ADR D3.7). No YouTube request before the visitor clicks.
- No real Bridge data or client documents; every placeholder marked in brackets (`[texto de Bridge]`, `[muestra de Bridge, documento anonimizado]`) and listed in `docs/placeholder-register.md`.
- Spanish copy in `usted`; test names in English; each test file header cites the story and spec test numbers.
- Type ceiling: hero `h1` ≤ 4.5rem, chapter monuments ≤ 4rem. Section padding at ≥ 64rem ≈ 40 % below R2's 8rem (target 4.75rem).
- Gates before PR: `npm test` green, `node check.mjs <every page>` green at 1440/390/320 with motion on and off, C3 mutations killed, one independent review (mode C, `docs/global/metodologia-sdd-tdd.md`).
- Git: branch `feature/BRG-84-remaster-r3` from `develop`; never push to `develop`/`main`; PR to `develop`, owner merges.

## Review Focus

1. **JavaScript off:** tiles visible as a static grid, video poster is a working link to the YouTube page, language band and forms usable. → Tasks 3, 4, 5.
2. **320 px width:** tiles, video block, language band and new pages without overflow or clipped text. → `check.mjs` in Task 10, plus the clip assertion in Task 1.
3. **Keyboard inside the moving tiles:** focus pauses the loop, each real tile reached once, copies never focusable. → Task 4.
4. **Non-Latin language names** in the band (Árabe/العربية, Chino/中文, Ruso/Русский): correct `lang`, Arabic `dir="rtl"`, no clipping. → Task 3.
5. **Unknown or hostile query values** on forms and the thank-you page (`?idioma=xyz`, `?servicio=<script>`): ignored, never injected as HTML. → Tasks 3, 8.
